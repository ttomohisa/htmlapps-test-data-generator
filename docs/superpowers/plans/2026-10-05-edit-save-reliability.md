# Edit, generate, and save reliability

**Goal:** Make the existing 23-generator, four-format workflow reliable while editing.
**Architecture:** Keep the standalone HTML and worker generator. Validate before numeric coercion, restore column focus by stable ID and control, and invalidate old workers at every source boundary.
**Spec:** APP_SPEC.md, column operations, reproducibility, and export contracts.

## Constraints and review focus
- No new generator or format, runtime dependency, network behavior, or stress fixtures.
- Blank numeric settings must not silently become zero; explicit allowed zero remains valid.
- Reordering at either edge, repeated type changes, deleting the last row, and Undo must leave usable focus.
- Name/type controls need Japanese and English accessible names at every width.
- Editing during generation or saving must reject late old-worker messages.
- CSV/TSV quotes, commas, tabs, BOM and line endings must round-trip alongside JSON/JSONL.
